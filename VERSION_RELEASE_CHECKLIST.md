# Future Stable Release Criteria

SemShift is currently prepared as a `v0.2.0` alpha/trust release, not a stable release.

Remaining work before a stable release:

- External human-labeled benchmark with documented methodology.
- Calibrated thresholds per mode.
- More golden tests for policy, prompt, research, resume, and README workflows.
- Optional deep/NLI contradiction detection behind an explicit flag.
- Cross-platform CI history on Python 3.10, 3.11, and 3.12.
- GitHub Action usage validated in a real pull request workflow.
- More documentation for false positives and missed drift reports.
- Stable public API review after more user feedback.
