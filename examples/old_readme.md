# AcmeSearch

AcmeSearch is a local-first library for semantic search experiments.

## Installation

Requires Python 3.10 or later.

```bash
pip install acmesearch
```

## Features

- Runs locally with open-source embeddings.
- Supports Markdown and text files.
- Experimental ranking may produce inaccurate matches.
